## 🌟 Giới thiệu tổng quan

Website là sản phẩm thuyết trình và số hóa học tập toàn diện về xã An Nhơn Tây, Củ Chi (thuộc Thành phố Hồ Chí Minh mở rộng theo Nghị quyết 202/2025/QH15). Dự án cung cấp:
- **Khám phá An Nhơn Tây:** Hệ thống bài viết chuyên đề sâu sắc về Địa đạo Bến Dược, Địa đạo Bến Đình, Làng nghề Bánh tráng Phú Hòa Đông, Làng mây tre đan Thái Mỹ, Nông trang Xanh Green Noen, Vườn trái cây Trung An, Bò tơ An Nhơn Tây.
- **Bản đồ Văn hóa & Hành chính Tương tác:** Bản đồ Leaflet tích hợp đầy đủ **34 đơn vị hành chính cấp tỉnh Việt Nam sau sáp nhập 2025** (Nghị quyết 202/2025/QH15 & sapnhap.bando.com.vn) cùng **8 tọa độ di tích lịch sử và văn hóa đã xác minh** tại An Nhơn Tây.
- **Thư viện Tư liệu & Hình ảnh:** Thư viện đa phương tiện trực quan về đời sống, văn hóa và truyền thống vùng đất thép thành đồng.
- **Tổng quan Kinh tế - Xã hội:** Các chỉ tiêu diện tích (77.70 km²), dân số (40.896 người), hạ tầng giao thông và định hướng nông nghiệp công nghệ cao.

## 🛠️ Công nghệ sử dụng

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4, Lucide Icons
- **Mapping:** Leaflet.js, Esri World Imagery & Street Map
- **Deployment:** GitHub Pages via GitHub Actions

---

## 🚀 Hướng dẫn chạy thử trên máy tính (Local)

1. Clone repository:
   ```bash
   git clone https://github.com/luong200915-lab/annhontay.git
   cd annhontay
   ```

2. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```

3. Khởi chạy máy chủ phát triển:
   ```bash
   npm run dev
   ```
   Mở trình duyệt tại: `http://localhost:3000`

4. Đóng gói cho môi trường production:
   ```bash
   npm run build
   ```
